Windose application platform

Breeze API Reference

Build native-looking Windose applications from editable scripts. Browse every current language statement, GUI binding, event, and runtime function here.

Quick start

Create the controls, place them in a layout, register events, then show the completed window.

let main = window("My App", 120, 100, 600, 400);
let root = windowRoot(main);
let status = statusBar();
dock(root, status, "bottom");
let statusText = statusPanel(status, "Ready", 400);
let body = stackPanel("vertical");
dock(root, body, "fill");
let input = textField("World", 26);
let action = button("Greet", 100, 28);
stack(body, input);
stack(body, action);

on action.click {
    set statusText.text = "Hello, " + value(input, "text");
}

show(main);
Disk scripts are loaded from 0:\Apps\main.breeze. The Cosmos VFS must be mounted first.

Language statements

let

Statement
let name = expression;

Creates a named value. Variables can hold strings, numbers, booleans, controls, windows, and returned native objects.

Variable assignment

Statement
name = expression;

Changes an existing variable. Variables declared inside a function are local to that call.

set

Statement
set target.property = expression;

Changes a supported GUI property and marks that component for redraw.

Comments and expressions

Syntax
// Arithmetic: + - * /
// Comparison: == != < <= > >=
// Logic: ! && ||
let message = "Count: " + (4 * 3);

+ joins values when either side is text. Logical AND and OR short-circuit.

Control flow

if and else

Statement
if (count > 10) {
    print("large");
} else {
    print("small");
}

else if chains are supported.

while

Statement
while (count < 10) {
    count = count + 1;
}

Loops are limited to 10,000 iterations, and each run or event is limited to 100,000 operations.

Functions

function and return

Declaration
function double(value) {
    return value * 2;
}
let result = double(21);

Parameters and variables declared in the function are local. Calls are limited to 64 levels.

Script lists

List functions

Collection
let items = list();
listAdd(items, "Desktop");
let first = listGet(items, 0);
listSet(items, 0, "Documents");
let count = listCount(items);
let removed = listRemove(items, 0);

Script lists hold arbitrary values and are separate from the visual ListView control. Indexes start at zero.

Events

on ... click

Event
on saveButton.click {
    set statusText.text = "Saved";
}

Supported by Button and MenuItem.

select and doubleClick

Event
on files.select {
    set statusText.text = value(event, "text");
}

Supported by TreeView and ListView. Inside the handler, event contains the selected item.

Properties

Function

Reads a supported property. Components expose text, width, height, and visible.

Windows and layout

window

Constructor
window(title, x, y, width, height)

Creates and returns a titled Window. It is not registered or displayed until passed to show.

windowRoot

Layout
windowRoot(window)

Creates a stretching DockPanel, reserves title-bar space, adds it to the window, and returns it.

dockPanel

Constructor
dockPanel()

Creates an empty DockPanel for edge-based application layout.

dock

Layout
dock(parent, child, "top" | "bottom" | "left" | "right" | "fill")

Adds a child to a DockPanel. Add edge controls first and the fill control last.

stackPanel

Constructor
stackPanel("vertical" | "horizontal")

Creates a container that places children sequentially.

stack

Layout
stack(stackPanel, child)

Adds a child and recalculates stack positions.

add

Layout
add(parent, child)

Adds a child directly without dock or stack layout. Use it for manually positioned components.

Controls

Controls

statusBar and statusPanel

Controls

statusPanel returns a Panel. Update it with set count.text = ....

TreeView

treeView, treeRoot, treeChild

Data view
let tree = treeView();
let drive = treeRoot(tree, "Drive C", "0:\\");
treeChild(drive, "System", "0:\\System");

The tag argument is application data, normally a path. It becomes the event item's path property.

ListView

List functions

Data view
let files = listView("details");
listItem(files, "System", "0:\\System", true);
listMode(files, "icons");
listClear(files);

Modes are icons, smallicons, list, and details. listItem returns the new item.

ScrollView

scrollView

Layout
let fileScroll = scrollView(files);
dock(body, fileScroll, "fill");

Wraps content in a scrollable viewport. Dock the returned ScrollView, not the original content.

Filesystem

loadDirectory

Filesystem
loadDirectory(list, path);

Clears a ListView and fills it with directories and files using System.IO. The Cosmos VFS must be mounted and the path must exist.

Application lifecycle

process / stopProcess

Runtime
let worker = process("File Indexer");

on worker.update {
    // Perform a small amount of background work.
}

stopProcess(worker);

process(name) creates a headless Breeze process and names the current application process. It appears in Task Manager and remains alive without a window. stopProcess(process) stops it and closes its owned windows. Read its name and running properties with value.

The update handler runs cooperatively once per scheduler update, not on a separate thread, so it must return quickly.

Native C# process protection

process.canTerminate = false; // Protected from End Task.
process.canTerminate = true;  // User may end it.

Native processes are protected by default, while Breeze application processes are terminable by default. Breeze scripts cannot change canTerminate yet; protection is currently a native C# setting.

timer

Runtime
let clock = timer(1000);

on clock.tick {
    print("tick");
}

stopTimer(clock);
startTimer(clock);

Creates a repeating millisecond timer. Its tick handler runs cooperatively during the owning process update. Read the interval and active properties with value.

Process messages

Runtime
// Receiver
let app = process("File Indexer");
on app.message {
    print(value(event, "sender"));
    print(value(event, "name"));
    print(value(event, "data"));
}

// Sender
let target = findProcess("File Indexer");
send(target, "scan", "0:\\Documents");

findProcess(name) obtains a running named Breeze process. send queues a named value for it and returns false if its bounded queue is full. Messages are delivered in order with a limited number processed per scheduler update.

show

Runtime
show(window);

Queues registration with WindowManager, focuses the window, and creates its taskbar button.

close

Runtime
close(window);

Posts a safe close message. WindowManager removes the window and taskbar button.

Utility

print

Debug
print(value);

Writes a value followed by a newline to serial output.

BreezeHost

C# API
BreezeHost.RunSource(sourceText);
BreezeHost.RunFile(@"0:\Apps\main.breeze");

Runs source already in memory or loads it from the mounted VFS. Errors appear in a Breeze Error window.

Current limitations

Breeze does not yet support imports, modules, classes, custom objects, exception handling, file writing helpers, or general-purpose threads. Headless process update handlers are cooperative and run on the main scheduler. Native GUI types still need to be added in C# before scripts can use them.
